ROLL FIGHT CLUB — PROJETO PARA VS CODE

Como abrir:
1. Extraia o arquivo ZIP.
2. Abra a pasta roll-fight-club no Visual Studio Code.
3. Abra index.html no navegador ou use a extensão Live Server.

Estrutura:
- index.html: conteúdo e estrutura do site.
- style.css: cores, layout e responsividade.
- imagens/: logo e imagens utilizadas pelo site.

Observação:
As imagens foram geradas por IA para este projeto. Os retratos são ilustrativos,
não fotografias documentais dos atletas mencionados. O clube é um conceito fictício.
